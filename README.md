# 📚 Data Structures & Algorithms (DSA) Lab

Welcome to my **Data Structures & Algorithms (DSA) Lab** repository. This repository contains all the lab assignments, practice problems, and implementations completed during my DSA course using **C++**.

## 🚀 Course Overview

This repository covers the fundamental concepts of Data Structures and Algorithms, including:

- Arrays
- Strings
- Pointers
- Linked Lists
- Stacks
- Queues
- Recursion
- Searching Algorithms
- Sorting Algorithms
- Trees
- Binary Search Trees (BST)
- Heaps
- Hashing
- Graphs
- Dynamic Programming (Basic)
- Time & Space Complexity Analysis

## 🛠️ Language Used

- **C++**
- Standard Template Library (STL)


## 🎯 Objectives

- Understand core Data Structures.
- Learn efficient algorithm design.
- Improve problem-solving skills.
- Analyze time and space complexity.
- Build a strong foundation for competitive programming and technical interviews.
